# Sobrecarga de Operadores.

En este directorio se encuentra un ejemplo donde se demuestra el uso de
sobrecarga de operadores, creando como ejemplo una estructura que define
números complejos.

Se definen las cuatro operaciones básicas: Suma, Resta, Multiplicación y División, tanto entre números complejos, como entre valores numéricos y números complejos.

## Contenido.
* ```complejos.cpp```: Ejemplo en donde se encuentra tanto la definición de la estructura como código que permite probar su uso.
* ```Makefile```: Archivo que permite automatizar el proceso de compilación de los programas.
* ```LEEME.md```: Este documento.
