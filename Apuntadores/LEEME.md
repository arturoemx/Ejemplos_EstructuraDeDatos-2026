# Apuntadores
En este directorio se encuentran ejemplos del uso de apuntadores que vimos en clase.

# Contenido
En la carpeta se encuentran los siguientes archivos:

* ```ejApuntadores1.cpp```: Ejemplo básico en donde se muestra el uso de los operadores monarios ```*``` y ```&```.
* ```ejApuntadores2.cpp```: Ejemplo básico donde se muestra el uso de apuntadores con arreglos y se ilustra el concepto de aritmética de apuntadores.
* ```ejArreglos.cpp```: Ejemplo donde muestra diferentes formas de acceder a los elementos de un arreglo.
* ```Makefile```: Archivo que permite automatizar el proceso de compilación de los programas.
* ```LEEME.md```: Este documento.
